# Hineni Agency

### Soluções digitais para empresas

A **Hineni Agency** é uma agência digital focada no desenvolvimento de **sites, sistemas e soluções personalizadas** para empresas.

Nosso objetivo é transformar necessidades reais de negócio em soluções digitais modernas, funcionais e escaláveis.

---

## 🚀 O que fazemos

* 🌐 Desenvolvimento de sites e landing pages
* 💻 Sistemas e aplicações web
* 📊 Sistemas de gestão e CRM
* 🤖 Automação de processos
* 🔗 Integrações com APIs e serviços externos
* ⚡ Soluções digitais personalizadas

---

## 🛠️ Tecnologias

Trabalhamos com tecnologias modernas do ecossistema web, incluindo:

`React` · `JavaScript` · `TypeScript` · `Node.js` · `Vite` · `Tailwind CSS` · `Supabase` · `Git`
